# Бэкенд «Хаски: Зов Севера»

Один процесс на aiogram 3 + aiohttp: бот с кнопкой запуска мини-приложения,
HTTP-API для прогресса и раздача самого html-файла игры.

## Файлы

| файл | что внутри |
|---|---|
| `main.py` | точка входа: поднимает API и long polling бота |
| `bot.py` | хэндлеры `/start`, `/play`, `/top`, кнопка `WebAppInfo` |
| `api.py` | `POST /api/load`, `POST /api/save`, `POST /api/top`, `GET /` |
| `tg_auth.py` | проверка подписи `Telegram.WebApp.initData` |
| `storage.py` | SQLite: один сейв на игрока + таблица лидеров |
| `config.py` | настройки из переменных окружения |

## Запуск

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r server/requirements.txt
export BOT_TOKEN=... WEBAPP_URL=https://твой-домен/
python -m server.main          # из корня проекта, рядом с папкой server/
```

Игра откроется на `http://localhost:8080/`, но Telegram пускает мини-приложения
только по https — на сервере поставь перед ним nginx с сертификатом или
выложи html отдельно (тогда укажи в игре `CFG.API = 'https://api.твой-домен'`,
CORS уже разрешён).

Дальше у @BotFather: `/newapp` → ссылка на `WEBAPP_URL`, и в html-файле игры
заполни `CFG.BOT_LINK` (для кнопки «Позвать») и `CFG.API`
(`''` — если игру раздаёт этот же сервер).

## API

Авторизация у всех ручек одна — `initData` в теле запроса, никаких куки и сессий.

| ручка | тело | ответ |
|---|---|---|
| `POST /api/load` | `{initData}` | `{save, serverTime}`, `save: null` у новичка |
| `POST /api/save` | `{initData, save}` | `{status:"ok"}` · `{status:"stale", save}` · 429 при частых записях |
| `POST /api/top` | `{initData}` | `{top: [...20], rank}` |

`stale` означает, что присланный прогресс младше серверного — клиент
откатывается на серверную версию и показывает тост.

## Чего здесь нет

Сервер хранит сейв, но не считает игру: он проверяет подпись, размер,
частоту записи и то, что `stats.life` и `bestStage` не уменьшаются.
Игрок с DevTools всё ещё может отправить завышенный сейв.
Для турниров с реальными призами нужно переносить на сервер сам цикл —
доход в секунду, слияния и результат забега — и отдавать клиенту только
состояние. Текущая схема рассчитана на игру в канале, где цена читерства — место в `/top`.
